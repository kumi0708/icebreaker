## 1. 公開法務ページ

正本は `AppStore/legal_page.html`。公開先は SexyCounter と同じ `kumi0708/sexycounter-legal` の `icebreaker/index.html`
（`ledtimer/`・`smorpurelove/`・`vibe/` と同じ並び）。

```bash
gh api --method PUT repos/kumi0708/sexycounter-legal/contents/icebreaker/index.html \
  -f message="icebreaker: プライバシーポリシー/サポートを追加" \
  -f content="$(base64 -i AppStore/legal_page.html)"
gh api repos/kumi0708/sexycounter-legal/pages/builds --jq '.[0].status'   # built になるまで待つ
```

更新するときは `-f sha="$(gh api repos/kumi0708/sexycounter-legal/contents/icebreaker/index.html --jq .sha)"` を付ける。
**アプリの挙動を変えたら、このページも同時に見直す**（SexyCounter で公開ページだけ取り残された事故あり）。

## 3. ビルドのアップロード（Mac）

SexyCounter 1.3.x と同じく、Xcode にサインイン済みのアカウントで CLI から上げる。

```bash
xcodebuild -project IceBreaker.xcodeproj -scheme IceBreaker -configuration Release \
  -destination 'generic/platform=iOS' -archivePath build/IceBreaker.xcarchive \
  -allowProvisioningUpdates archive
xcodebuild -exportArchive -archivePath build/IceBreaker.xcarchive \
  -exportOptionsPlist AppStore/ExportOptions.plist -exportPath build/export \
  -allowProvisioningUpdates
```

CLI で "No Accounts" になったら `open build/IceBreaker.xcarchive` → Organizer → Distribute App → App Store Connect → Upload。

再アップロード時は `CURRENT_PROJECT_VERSION`（ビルド番号）を上げる。
